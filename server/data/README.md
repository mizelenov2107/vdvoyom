# Данные-примеры

Здесь лежат урезанные образцы справочников, чтобы сервер запускался из коробки.
В рабочей версии каталоги больше: фильмы собираются скриптом `scripts/build-movies.py`
(Wikidata + рейтинги), места и идеи — из своих подборок, картинки к ним подтягивает
`scripts/hd-images.mjs`. Постеры и фото в репозиторий не входят: у них свои правообладатели.
